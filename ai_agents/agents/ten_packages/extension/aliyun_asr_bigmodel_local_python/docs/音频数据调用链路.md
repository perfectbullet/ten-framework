
## 调用链分析

### 1. VAD 有音频要开始了有没有时间发送到 ASR？

**有**，音频通过 TEN 框架的数据流传递：



```
VAD._send_audio_frame()
  ↓ (TEN 框架数据流)
ASR.on_audio_frame()
  ↓
audio_frames_queue.put(audio_frame)
  ↓
_audio_frame_consumer() (后台任务，持续消费队列)
  ↓
_handle_audio_frame()
  ↓
send_audio() ← 这里检查 self.connected
```

### 2. 触发哪个方法的调用，触发了 `not self.connected`？

调用链：

1. **VAD** 转发音频 → TEN 框架传递到 **ASR**
2. **ASR.on_audio_frame()** (第 83-86 行) - 将音频放入队列
3. **_audio_frame_consumer()** (第 477-485 行) - 后台循环消费队列
4. **_handle_audio_frame()** (第 419-469 行) - 处理音频帧
5. **send_audio()** (第 468 行) - 调用子类实现

在 `_handle_audio_frame()` 第 **427 行**检查 `is_connected()`：



```python
if not self.is_connected():
    ten_env.log_debug("send_frame: service not connected.")
    # 丢弃音频
    return
```

然后在 **send_audio()** 第 **489 行**再次检查：



```python
if not self.recognition or not self.connected:
    return False  # ← 这里返回 False，音频被丢弃
```

### 3. 被重载的方法（override）调用时机

| 方法                 | 调用时机                                               |
| -------------------- | ------------------------------------------------------ |
| `on_init()`          | 扩展初始化时（第 69-71 行）                            |
| `on_start()`         | 扩展启动时（第 73-81 行），调用 `start_connection()`   |
| `on_audio_frame()`   | **每次收到音频帧时**（第 83-86 行）                    |
| `on_data()`          | 收到 `asr_finalize` 数据时（第 88-116 行）             |
| `on_stop()`          | 扩展停止时（第 117-128 行）                            |
| `vendor()`           | 多处调用，返回厂商名称                                 |
| `start_connection()` | 在 `on_start()` 时调用                                 |
| `is_connected()`     | **频繁调用**，检查连接状态                             |
| `stop_connection()`  | 在 `on_stop()` 或 `finalize()` 后调用                  |
| `send_audio()`       | 在 `_handle_audio_frame()` 中调用                      |
| `finalize()`         | 在 `on_data()` 收到 `asr_finalize` 时调用（第 115 行） |
