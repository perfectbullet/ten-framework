**原有 15 个**：

- actually, in fact, correction, i think, i meant, nope, not really

## 🎯 关键改进

### 1. 解决 "打断一下" 检测问题
- **问题**：之前用户说 "打断一下" 无法触发打断
- **原因**：配置中只有 "我打断一下"
- **解决**：添加 "打断" 和 "打断一下" 到高优先级

### 2. 覆盖更多口语表达
- **停停** / **停停停** - 重复强调的打断
- **等会儿** / **稍等** - 更自然的口语
- **别说了别说了** - 强调的打断

### 3. 增强低优先级打断
- **不是那个意思** - 纠正误解
- **我想问** / **我有问题** - 想要提问
- **听我说** / **让我说完** - 请求表达机会

根据 `interruption_threshold: "medium"` 的配置：
1. ✅ 检查高优先级关键词
2. ✅ 检查中优先级关键词
3. ❌ 不检查低优先级关键词（需要设置为 "low"）

## 🎯 使用建议

### 场景 1: 严格打断模式（推荐）
**配置**：`interruption_threshold: "high"`
**触发**：只检测高优先级关键词
**适用**：重要的系统通知、关键信息播报

### 场景 2: 标准打断模式（当前）
**配置**：`interruption_threshold: "medium"`
**触发**：高 + 中优先级关键词
**适用**：一般对话、问答系统

### 场景 3: 宽松打断模式
**配置**：`interruption_threshold: "low"`
**触发**：所有关键词
**适用**：需要频繁交互的场景
