## 💡 使用建议

### 严格模式（推荐用于重要场景）
```json
"interruption_threshold": "high"
```
只检测：停、打断、停止等强烈打断词

### 标准模式（当前配置）
```json
"interruption_threshold": "medium"
```
检测：高 + 中优先级（共 54 个关键词）

### 宽松模式
```json
"interruption_threshold": "low"
```
